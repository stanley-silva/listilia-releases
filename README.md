# Listilia 🛒

**Suas compras organizadas, seus gastos sob controle.**

Listilia é um aplicativo Android para organizar listas de supermercado, planejar compras e acompanhar os gastos mensais de forma simples e intuitiva.

## Funcionalidades

- Criação e gerenciamento de listas de compras.
- Planejamento de compras futuras.
- Registro de compras realizadas.
- Organização de produtos por categorias.
- Controle de preços e quantidades.
- Resumo mensal de gastos.
- Histórico de compras.
- Funcionamento offline.

## Download

Acesse a seção **Releases** deste repositório para baixar a versão mais recente do aplicativo Android.

## Instalação

1. Baixe o arquivo APK disponível em Releases.
2. Abra o arquivo no seu celular Android.
3. Autorize a instalação de aplicativos dessa origem, quando solicitado.
4. Instale o Listilia.

> O aplicativo está em fase beta e pode apresentar instabilidades.

Desenvolvido para tornar as compras do dia a dia mais simples.
